## 2. 서명 키 (가장 중요)

- 파일: `upload-keystore.jks` + 비밀번호 파일(`keystore.properties` 내용과 같음, 별칭 `upload`)
- **git에 절대 올리지 않음** (저장소 공개). 사용자가 따로 보관 중.
- 새 세션에서 빌드하려면 사용자에게 두 파일을 받아서 아래처럼 둔다:
  - `android/upload-keystore.jks`
  - `android/keystore.properties` (storeFile=upload-keystore.jks, storePassword, keyAlias=upload, keyPassword)
- 인증서 SHA-256 지문(맞는 키인지 확인용):
  `0D:D5:B7:56:1F:DA:D4:CD:23:AD:2E:A2:62:CC:EA:2F:A5:E2:16:12:28:48:23:96:66:25:62:C2:A4:A0:45:BF`
  확인: `keytool -list -keystore android/upload-keystore.jks -storepass <비밀번호>`
- **키를 새로 만들면 플레이스토어 업데이트가 불가능하다. 절대 새로 만들지 않는다.**

## 3. 빌드 환경 만들기 (새 컨테이너에서 1회, 약 2~3분)

```bash
# Android SDK (Java 21은 기본 설치되어 있음)
mkdir -p /opt/android-sdk && cd /opt/android-sdk
curl -sLo clt.zip "https://dl.google.com/android/repository/$(curl -s https://dl.google.com/android/repository/repository2-1.xml | grep -o 'commandlinetools-linux-[0-9]*_latest.zip' | head -1)"
unzip -q clt.zip && mkdir -p cmdline-tools/latest && mv cmdline-tools/bin cmdline-tools/lib cmdline-tools/NOTICE.txt cmdline-tools/source.properties cmdline-tools/latest/
yes | cmdline-tools/latest/bin/sdkmanager --sdk_root=/opt/android-sdk --licenses >/dev/null
cmdline-tools/latest/bin/sdkmanager --sdk_root=/opt/android-sdk "platform-tools" "platforms;android-36" "build-tools;36.0.0" "build-tools;35.0.0"

# 프로젝트
cd <저장소> && npm install
echo "sdk.dir=/opt/android-sdk" > android/local.properties
```

빌드:
```bash
npm run build && npx cap sync android && cd android && ./gradlew assembleRelease   # 테스트용 APK
./gradlew bundleRelease                                                              # 출시용 AAB
```
- APK: `android/app/build/outputs/apk/release/app-release.apk`
- AAB: `android/app/build/outputs/bundle/release/app-release.aab`
- 버전 올리기: `android/app/build.gradle`(versionCode·versionName) + `src/screens/Settings.tsx`(APP_VERSION)

화면 확인: `npx vite preview --port 4173` 후 Playwright(Pixel 7)로 캡처.

## 4. 앱 구조

- React 19 + Vite + TypeScript + Capacitor 8 (Android)
- 하단 탭: 홈 / 분석 / 차트분석 / 고래(큰손 추적·관심 주소) / 설정
- 주요 파일
  - `src/App.tsx` — 탭·화면 이동, 뒤로가기(규칙: 창·선택·수정 취소 → 이전 화면 → 홈에서 종료 확인)
  - `src/lib/api.ts` — 시세·체인 통계·주소 조회 / `src/lib/whale.ts` — 고래 감지, LTH/STH
  - `src/lib/indicators.ts` — 분석 탭 13개 지표·시장 온도 / `src/lib/outlook.ts` — 상승 가능성
  - `src/lib/ta.ts` — 차트 기술적 분석 / `src/lib/dominance.ts` — 도미넌스
  - `src/lib/alerts.ts` — 큰손 거래소 입금 알림 / `src/lib/glossary.ts` — 용어 사전
  - `src/components/CandleChart.tsx` — lightweight-charts 5.2.1 캔들 차트
- 앱 문구는 누구나 이해할 쉬운 말. 어려운 용어는 `<Term k="...">`로 설명 팝업.

## 5. 데이터 소스와 주의점 (이번 개발 중 알게 된 것)

| 데이터 | 소스 | 주의 |
|---|---|---|
| 12개 코인 통계 | Blockchair `/stats` | 무료 한도 작음. 검색(쿼리) API는 IP 차단당하기 쉬워서 쓰지 않음 |
| BTC 수수료·블록·주소 | mempool.space | 안정적 |
| BTC 5년 차트 | blockchain.info charts (`cors=true`) | MVRV·실현가격은 무료 제공 안 됨 |
| ETH 가스·주소 | Blockscout | 토큰 목록 API가 매우 느림(20초+) → 따로 비동기 로드 |
| ETH 블록·로그, SOL | PublicNode RPC | 가끔 CORS 거부/차단. SOL은 mainnet-beta가 브라우저에서 403 |
| 시세 대체 | CoinGecko → Coinbase → Kraken | CoinGecko는 공유 IP에서 자주 제한 |
| 캔들 | Coinbase (300개/요청), 대체 Kraken | Binance는 지역 차단(451) |
| 스테이블코인 | DefiLlama | `stablecoincharts/all?stablecoin=1`은 CORS 헤더가 중복돼 브라우저에서 막힘 → `/stablecoin/1` 사용 |
| 전체 시총 과거(도미넌스 차트) | CoinMarketCap data-api | **CORS 없음 → 앱에서는 CapacitorHttp(네이티브)로만 받음.** 브라우저 미리보기에선 현재값만 표시 |
| 환율 | open.er-api.com | |

- 거래소 지갑 판별: 알려진 주소 목록(`whale.ts`) + 누적 거래 수 많은 주소를 "거래소 추정"
- 알림은 앱 실행 중·재실행 시에만 검사(백그라운드 서버 없음)
- 상승 가능성은 과거 5년 비슷한 날 기반 통계. 장기(1년)는 표본이 한 시기에 몰려 "믿을 만한 정도 낮음" 표시
